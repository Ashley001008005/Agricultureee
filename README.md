🌱 Tanikala — Agricultural Management Website

Tanim. Ani. Suplay. Kita.

Tanikala is a web-based agricultural website designed to connect farms, agricultural suppliers, and buyers through a user-friendly online platform. Its goal is to promote smarter agricultural operations, improve supply management, and simplify the connection between farm production and the market.

📖 About the Project

Tanikala focuses on providing an accessible digital platform for the agricultural industry. It features an agricultural-themed interface with information about the project, available services, contact details, and frequently asked questions.

The project aims to support the agricultural community by presenting agricultural solutions in an organized and user-friendly website.

✨ Features

- **Homepage** — Introduces Tanikala and its agricultural mission.
- **About Us** — Presents the project's background, mission, and vision.
- **Services Page** — Provides information about the agricultural services offered.
- **Contact Section** — Displays contact information for inquiries.
- **FAQs** — Provides answers to common questions.
- **Sign-Up Page** — Provides a starting point for user registration.
- **Responsive Interface** — Uses CSS to support a user-friendly browsing experience across different screen sizes.
- **Image Carousel** — Displays agricultural images through a navigable slideshow.
- **Dark Mode Toggle** — Allows users to switch the website's visual theme.
- **Interactive Elements** — Uses JavaScript to support website interactions.

*Note: The availability of functional registration, authentication, database operations, and other backend features depends on their implementation.*

🚀 Getting Started

You can run the website locally without installing a framework or package manager.

Prerequisites

- A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.
- Git, if you want to clone the repository.
- An internet connection for externally hosted fonts and icons.

Installation

1. Clone the repository

Open a terminal and run:

```bash
git clone https://github.com/Ashley001008005/Agricultureee.git
```

2. Navigate to the project folder

```bash
cd Agricultureee
```

3. Open the website

Locate `index.html` and open it in your web browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension to preview the website during development.

💻 Development

To modify the website:

1. Edit `index.html` to update the homepage structure and content.
2. Edit the files inside `css/` to customize the website's appearance.
3. Edit the JavaScript files inside `js/` to modify interactive behavior.
4. Update the images and other visual resources inside `assets/`.
5. Place additional website pages inside `html/`, keeping their file paths consistent with the existing links.

After making changes, refresh the browser to review the results.
